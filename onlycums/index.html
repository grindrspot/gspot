1. Verification Workflow

  • User sends /start and must tap ✅ I Agree to continue.
  • User submits username, birth year (must be 18+), then live selfie via Mini App camera.
  • Submission goes to admin review chat with Approve/Reject controls.
  • On approval: user receives one-time invite link and guidelines; group gets welcome post + guidelines.

2. User Commands

  • /start start verification
  • /status check verification status
  • /openapp open mini app dashboard
  • /menu quick action buttons
  • /help list commands
  • /myid show Telegram ID + admin access

3. Admin Commands

  • /ban <user_id> [reason]
  • /unban <user_id>
  • /broadcast_group <message>
  • /broadcast_all <message>
  • /export_ids
  • /clear_pending
  • /addadmin <user_id>
  • /removeadmin <user_id>
  • /admins

4. Moderation Rules

  • No spamming or flooding.
  • No reporting the group.
  • No child sexual content (zero tolerance, immediate ban).
  • Respect admins and members.

Tip: Keep moderation decisions consistent. Reject unclear/fake submissions and ask user to re-submit.

5. Troubleshooting

  • Bot no response: verify webhook and web app runtime on PythonAnywhere.
  • Admin review chat unreachable: ensure bot is in review chat and has posting rights.
  • Users bypassing invite: rely on one-time links and auto-kick for non-approved joins.

Security: rotate bot token immediately if shared publicly.
