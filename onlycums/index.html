Admin Guidebook

Reference for moderation, verification approvals, invite control, trust scoring, and daily activity automation.

Verification Flow

  • User sends /start and taps ✅ I Agree.
  • User submits username, birth year (18+), then live selfie via mini app.
  • Admin gets review item with approve/reject reason actions.
  • Approval sends one-time invite link and posts in group.

User Commands

  • /start, /onboarding, /status, /openapp
  • /menu, /myid, /help, /cancel

Admin Commands

  • /admin, /analytics, /digest, /toptoday
  • /sendbroadcast, /broadcast_all, /broadcast_group
  • /resendinvite <user_id|@username>
  • /clear_pending, /export_ids
  • /addadmin <user_id|@username>, /removeadmin <user_id>, /admins
  • /ban, /unban, /cancelmode

Trust Scoring

  • Each pending user gets a trust score (0-100) with risk level.
  • Shown in admin queue and verification request details.
  • Factors include username quality, status history, submission behavior, bans.

Automations

  • Daily leaderboard: posts top active chatters at 9:00 PM PHT.
  • Leaderboard includes both Telegram profile photos and latest verification photos when available.
  • Weekly digest: submission/approval/rejection/pending metrics to admin review chat.

Troubleshooting

  • Bot no response: check webhook status and reload PythonAnywhere web app.
  • Approve/reject issue: verify callback buttons on newest pending item.
  • Invite failures: use /resendinvite and ensure user has started bot chat.
  • Broadcast partial failures: blocked users return 403 and are counted as failed deliveries.
