Admin Guidebook

Use this manual for daily moderation, approvals, escalation, and bot troubleshooting. This page mirrors the core G-Spot visual system for a consistent operator experience.

Owners: 8488339614, 6006722117 Review Chat: -1003745386694 Max Re-Verify: 5

Verification Flow

  • User sends /start and taps ✅ I Agree.
  • Collect username, birth year (must be 18+), and live selfie.
  • Submission appears in admin review chat and panel.
  • Approve sends one-time invite link and guidelines automatically.

User Commands

  • /start Start verification
  • /status Check review status
  • /openapp Open mini app
  • /menu Show quick buttons
  • /myid Show Telegram ID
  • /help Command list

Admin Commands

  • /ban <user_id> [reason]
  • /unban <user_id>
  • /broadcast_group <message>
  • /broadcast_all <message>
  • /export_ids
  • /clear_pending
  • /addadmin <user_id>
  • /removeadmin <user_id>
  • /admins

Community Rules

  • No spamming or flooding.
  • No reporting the group.
  • No child sexual content (instant ban).
  • Respect admins and members.

Troubleshooting and Escalation

  • If bot is silent, check webhook status and PythonAnywhere web app reload.
  • If submissions fail to reach review chat, confirm bot membership/permissions in -1003745386694.
  • If unapproved users enter group, verify auto-kick is enabled and bot is group admin.
  • If invite links are abused, keep one-time links and short expiry enabled.
